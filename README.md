# 🎓 AI Study Planner

An AI-powered study planner that generates personalized timetables based on your subjects, difficulty levels, and available study hours.

## 🚀 Features
- Add multiple subjects with difficulty levels
- AI generates a smart day-by-day study schedule
- Pomodoro timer built in
- Save subjects to MongoDB database
- Beautiful dark themed UI

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI:** Groq AI (LLaMA 3.3 70B)

## ⚙️ How to Run
1. Clone the repo
2. Run `npm install`
3. Add your Groq API key in `.env` file
4. Run `node server.js`
5. Open `http://localhost:5000`
